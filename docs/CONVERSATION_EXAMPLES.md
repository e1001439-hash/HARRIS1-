# 本地多輪對話實際測試輸出

以下取自完整套件在 `/tmp/harris-contextual-dialogues-final.json` 寫出的實際程式輸出。資料全為虛構，使用真本地 PGlite、Store、分析／政策／placeholder驗證、Worker與通知流程；AI草稿由測試人工指定，LINE是收集送出內容的假實作。**不是實際模型生成品質或真實手機收發證據，也不是線上已更新的示意。**

首次介紹仍由實際Worker加入。部分不合格mock草稿會降級成該則安全簡答；沒有把fallback也宣稱為自然生成通過。下列不額外添加預期對話。

## 限制

- 上述五場景皆有實際assert通過，測試原始碼為 `test/contextual-worker.test.ts`；更多未知價格、日期營業、含混、注入、否定、錯價、再折扣與反轉claim在pure測試中驗證。
- 一旦requested仍立即轉人工，後續（包含道謝）不自動回客人，除非Harris明確恢復。這輪沒有為範例解除接手。
- 對話記憶依現有每客人30天／10turn有界歷史，無永久記憶；過久或超出上下文就詢問或交Harris。
- 真API的自然程度、placeholder通過率、實際通知送達及正式客人端到端仍未驗證。未推送部署或補發舊訊息。
